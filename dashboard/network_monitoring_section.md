# Dashboard / Network Monitoring Section

## Computer Networks Performance Metrics

1. **Bandwidth**: Measures the maximum rate of data transfer across a network at a given time.

2. **Latency**: The time it takes for data to travel from the source to the destination.

3. **Jitter**: The variance in latency of received packets, which can affect the quality of streaming applications.

4. **Packet Loss**: The percentage of packets that are lost during transmission, impacting the overall quality of the service.

5. **Throughput**: The actual rate at which data is successfully transferred from one point to another in the network.

6. **Error Rate**: The frequency of errors that occur during data transmission, which can indicate network issues.

7. **Connection Time**: The time required to establish a connection, important for user experience.

8. **Traffic Load**: Measures the amount of data being transmitted over a network, which can help in assessing network performance during peak and off-peak hours.

9. **Utilization Rate**: The percentage of the total bandwidth that is used, helping to identify potential bottlenecks.

10. **Network Availability**: The percentage of time that the network is operational and accessible to users.

These metrics are crucial for monitoring the performance of computer networks and ensuring optimal operation for network-centric applications.
