# Environmental Monitoring Dashboard

## Sensor Data Documentation

### Introduction
This document provides an overview of the sensors used in the environmental monitoring system for the Smart City IoT Street Light and Traffic System.

### Sensors Overview
- **Temperature Sensor**: Monitors the ambient temperature.
- **Humidity Sensor**: Measures the humidity level in the air.
- **Air Quality Sensor**: Detects levels of pollutants such as CO2 and VOCs.
- **Light Intensity Sensor**: Measures the brightness of the environment.

### Data Collection
Data from these sensors will be collected at regular intervals and sent to the central server for processing and visualization.

### Data Format
Each data entry will include:
- Timestamp (YYYY-MM-DD HH:MM:SS)
- Sensor Type
- Sensor Value

### Example Data Entry
- **Timestamp**: 2026-02-25 18:27:32
- **Temperature**: 22°C
- **Humidity**: 55%
- **Air Quality**: Good
- **Light Intensity**: 300 Lux

### Conclusion
This document is intended to serve as a guide for understanding the sensor data collected by the environmental monitoring system.
